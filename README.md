# Quiz Master - Examination Preparation System

![Quiz Master Screenshot](static/screenshot.png) <!-- Add screenshot if available -->

A Flask-based web application for administering and attempting quizzes with admin/user roles.

## Features

### Core Features
✅ **Admin Panel**  
- Manage subjects, chapters, quizzes, and questions  
- View all user attempts and scores  

✅ **User System**  
- Registration/Login with email verification  
- Quiz attempts with timer  
- Score history tracking  

✅ **Database**  
- SQLite with SQLAlchemy ORM  
- Programmatic initialization  

### Advanced Features
✨ RESTful API endpoints  
✨ Responsive Bootstrap UI  
✨ Form validation (frontend + backend)
